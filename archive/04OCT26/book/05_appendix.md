# ภาคผนวก

ภาคผนวกเก็บรายละเอียดที่ใช้ตรวจย้อนหรือทำซ้ำงาน ตารางที่สร้างจากไฟล์ข้อมูลและ workflow จริงมาจากสคริปต์ของโครงการ ตัวเลขจึงตรงกับเนื้อหาในบทที่ 3

## ภาคผนวก ก คำอธิบายกรณีใช้งานรายกรณี

## ภาคผนวก ฏ ตัวอย่างการคำนวณตัวชี้วัด

ตัวอย่างในภาคผนวกนี้มาจากแผนการวิเคราะห์ข้อมูล (docs/research_tools/Analysis_Plan.md) และเป็นค่าเป้าหมายของ unit test ใน analysis/tests/ ตัวเลขเป็นข้อมูลสมมติที่รู้คำตอบล่วงหน้า

**ฏ.1 Macro-F1 และอัตราการไม่สรุป** ผู้เข้าร่วมสมมติหนึ่งคนมี 20 รายการ ผลเทียบกับชุดคำตอบอ้างอิงเป็นไปตามตาราง ฏ.1

**ตารางที่ ฏ.1** ตาราง 3x4 ของผู้เข้าร่วมสมมติ

| อ้างอิง \ ระบบ | evidenced | partially | missing | abstained |
|---|---|---|---|---|
| evidenced | 6 | 1 | 0 | 1 |
| partially | 1 | 3 | 2 | 0 |
| missing | 0 | 0 | 5 | 1 |

คำนวณ precision (P) recall (R) และ F1 = 2PR/(P + R) ของแต่ละสถานะบนข้อที่ระบบสรุปได้ [@sokolova2009]

- evidenced: P = 6/7 และ R = 6/7 ได้ F1 = 0.8571
- partially: P = 3/4 และ R = 3/6 ได้ F1 = 0.6000
- missing: P = 5/7 และ R = 5/5 ได้ F1 = 0.8333
- Macro-F1 = (0.8571 + 0.6000 + 0.8333)/3 = 0.7635
- อัตราการไม่สรุป = 2/20 = 0.10
- ค่าประกอบที่นับ abstained เป็นการระบุผิด: recall ของ evidenced = 6/8 = 0.75 และของ missing = 5/6

**ฏ.2 Cohen's kappa ของการให้รหัสซ้ำ** [@cohen1960] รหัสสองรอบ 10 คู่ ตรงกัน 8 คู่ ได้ $p_o$ = 0.80 สัดส่วนขอบของสามสถานะในรอบที่ 1 เท่ากับ (0.4, 0.3, 0.3) และรอบที่ 2 เท่ากับ (0.3, 0.3, 0.4) ได้ $p_e$ = 0.4(0.3) + 0.3(0.3) + 0.3(0.4) = 0.33

$\kappa = (p_o - p_e)/(1 - p_e) = (0.80 - 0.33)/(1 - 0.33) = 0.7015$

ค่านี้สูงกว่าเกณฑ์ 0.61 [@landis1977]

**ฏ.3 ตัวชี้วัดของ RQ2** แผนหนึ่งมีรายการ I1 (ปรากฏสองแถว) และ I2 ผู้วิจัยรับคู่ I1 กับช่องว่าง g1 ปฏิเสธคู่ I1 กับ g2 และคู่ I2 กับ g3 ชื่อของ I2 ไม่ตรงกับคลัง ช่องว่างอ้างอิงของผู้เรียนคือ g1 ถึง g4 ชั่วโมงรวม 140 และ $H_{max}$ = 150
