# แบบประเมิน (เอกสารแนบยื่นจริยธรรม) v1.0-draft

เนื้อหาฉบับเต็มอยู่ที่ `docs/research_tools/Questionnaire_IOC_v1.0-draft.md` (ข้อคำถามคัดลอกจากภาคผนวก ข ของเล่มตรงตัว + แบบตรวจ IOC)

สำหรับยื่นคณะกรรมการ ให้แนบ:
1. ส่วนที่ 1 ของไฟล์ข้างต้น (แบบประเมิน 3 ข้อ + คำถามปลายเปิด 1 ข้อ + คำชี้แจงระดับ 1–5 และ "ไม่สามารถประเมินได้")
2. ภาพหน้าจอ Google Forms แบบประเมินที่สร้างจริง (หลังตั้งค่าตาม Setup Guide ขั้น 4)
3. ผล IOC ของผู้เข้าร่วมเชี่ยวชาญ 3 คน (ถ้าคณะกรรมการต้องการก่อนอนุมัติ)

ข้อมูลที่แบบประเมินเก็บ: เวลาตอบ · รหัสงาน · คะแนน 3 ข้อ · ข้อความปลายเปิด · **ไม่เก็บชื่อหรืออีเมล** (ตั้ง Forms ไม่ให้เก็บอีเมลสำหรับแบบประเมินนี้)
