> ⚠ ส่วนกฎหมายเป็นการเพิ่มใหม่ (DEC-32) ต้องให้อาจารย์ที่ปรึกษาและคณะกรรมการจริยธรรมพิจารณา ไม่ใช่ความเห็นทางกฎหมาย · หลักการทางเทคนิคมาจากเล่ม 3.5.1, 3.10, 3.11 และระบบที่สร้างแล้วใน `Final_IS/`

## 2. ฐานทางกฎหมายและหน้าที่ (ร่าง)
| ประเด็น | มาตรา | การปฏิบัติในโครงการ |

| ฐานในการประมวลผล | ม.19 ความยินยอม | ข้อคำถามบังคับในแบบฟอร์ม ระบบตรวจก่อนประมวลผล (`engine.validateIntake` → `consent_not_given`) · ขอแยกเป็นข้อชัดเจน อ่านเข้าใจง่าย ถอนได้ง่ายเท่ากับให้ |
| การแจ้งรายละเอียด | ม.23 | เอกสารชี้แจงผู้เข้าร่วม + ข้อความหัวแบบฟอร์ม: วัตถุประสงค์ ข้อมูลที่เก็บ ระยะเก็บ ผู้รับ สิทธิ ช่องทางติดต่อ |
| การส่งไปต่างประเทศ | ม.28 | ผู้ให้บริการอาจประมวลผลนอกประเทศ · ใช้ความยินยอมหลังแจ้งว่าปลายทางอาจมีมาตรฐานไม่เพียงพอ (หนังสือยินยอมข้อ 2) · ส่งเฉพาะข้อความหลังปิดบังให้โมเดล |

| แจ้งเหตุละเมิด | ม.37 (4) | แจ้งอาจารย์และคณะกรรมการทันที ประเมินหน้าที่แจ้งสำนักงานภายใน 72 ชั่วโมงนับแต่ทราบเหตุ |

## 5. ข้อจำกัดที่ต้องเปิดเผย (เล่ม 3.5.1, 3.10)
- ข้อมูลระบุตัวที่ไม่ตรงรูปแบบ (ชื่อ ที่อยู่ ชื่อบริษัท ชื่อสถาบัน) ยังอาจอยู่ในข้อความที่ส่งโมเดล
- ไฟล์ที่ส่งให้บริการอ่านข้อความยังไม่ผ่านการปิดบัง เพราะการปิดบังเกิดหลังได้ข้อความ
- หากคณะกรรมการกำหนดให้ปิดบังเพิ่ม ต้องปรับรูปแบบการปิดบังและรายงานผลกระทบต่อการตัดสินข้อกำหนด (ออก DEC และรันเทสต์ใหม่)
