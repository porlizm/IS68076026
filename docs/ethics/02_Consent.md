# หนังสือแสดงความยินยอมเข้าร่วมการวิจัย

ใช้ทั้งในแบบฟอร์มของคณะกรรมการ (ฉบับลงนาม ถ้าคณะกรรมการกำหนด) และเป็นข้อคำถามบังคับใน Google Forms คอลัมน์ "ความยินยอม" ของแท็บ `form_responses` ระบบตรวจค่านี้ก่อนประมวลผล ถ้าไม่ยินยอมจะถูกปฏิเสธทันทีและบันทึกเฉพาะเหตุการณ์ ไม่เก็บไฟล์ต่อ ค่าที่ระบบนับว่ายินยอม (`consent_yes` ใน `config/sheets.json`) คือข้อความที่ขึ้นต้นด้วย "ยินยอม" หรือ "ข้าพเจ้ายินยอม"

ข้าพเจ้าได้อ่านเอกสารชี้แจงผู้เข้าร่วมการวิจัยเรื่อง "กรอบการทำงานปัญญาประดิษฐ์เชิงสร้างสรรค์แบบหลายโมเดล เพื่อลดความคลาดเคลื่อนของข้อมูลในการวิเคราะห์ช่องว่างทักษะจากเรซูเม และการกำหนดเส้นทางการเรียนรู้เฉพาะบุคคล" และเข้าใจวัตถุประสงค์ สิ่งที่ต้องทำ ความเสี่ยง ประโยชน์ เส้นทางข้อมูล ระยะเวลาเก็บ และสิทธิในการถอนตัวแล้ว

**ข้อ 1 การเข้าร่วมวิจัย** ข้าพเจ้ายินยอมเข้าร่วมการวิจัย และยินยอมให้ผู้วิจัยเก็บ ใช้ และเก็บรักษาเรซูเม ข้อมูลในแบบฟอร์ม ผลวิเคราะห์ และคำตอบแบบประเมินของข้าพเจ้าเป็นเวลา 90 วันหลังส่งผล เพื่อวัตถุประสงค์ของการวิจัยนี้เท่านั้น

[ ] ยินยอม   [ ] ไม่ยินยอม

**ข้อ 2 การส่งข้อมูลไปยังผู้ให้บริการภายนอกที่อาจอยู่นอกประเทศไทย** ข้าพเจ้ารับทราบว่าไฟล์ PDF ของข้าพเจ้าจะถูกส่งให้ Google Cloud Document AI เพื่ออ่านข้อความ และข้อความหลังปิดบังอีเมล ลิงก์ หมายเลขโทรศัพท์ และเลขประจำตัวจะถูกส่งให้ OpenAI, Anthropic และ Google เพื่อวิเคราะห์ ซึ่งอาจประมวลผลในประเทศที่มีมาตรฐานคุ้มครองข้อมูลส่วนบุคคลต่างจากประเทศไทย และรับทราบว่าชื่อบุคคล ชื่อบริษัท และชื่อสถาบันการศึกษาอาจยังคงอยู่ในข้อความ ข้าพเจ้ายินยอมให้ส่งข้อมูลดังกล่าว

[ ] ยินยอม   [ ] ไม่ยินยอม

ต้องยินยอมทั้งสองข้อ ระบบจึงประมวลผล แบบฟอร์มมีคอลัมน์ความยินยอมคอลัมน์เดียว จึงใช้ข้อความเดียวที่รวมทั้งสองข้อ คือ "ข้าพเจ้ายินยอมตามข้อ 1 และข้อ 2"

ข้าพเจ้าทราบว่าถอนตัวหรือขอให้ลบข้อมูลได้ทุกเมื่อโดยไม่มีผลกระทบ ทางอีเมลที่ระบุในรายงาน

| | |
|---|---|
| ลงชื่อผู้เข้าร่วม (ถ้าใช้ฉบับกระดาษ) | ____________________ วันที่ ________ |
| ลงชื่อผู้วิจัย | ____________________ วันที่ ________ |

**ข้อความหัวแบบฟอร์ม Google Forms (ฉบับย่อ)** การวิจัยนี้ขอเรซูเมภาษาอังกฤษ (PDF ไม่เกิน 10 MB ไม่เกิน 5 หน้า) เพื่อวิเคราะห์ว่ามีข้อความรองรับข้อกำหนดของอาชีพเป้าหมายข้อใด แล้วส่งรายงานภาษาไทยพร้อมแผนการเรียนรู้กลับทางอีเมลที่ยืนยันตัวตนของท่าน ไฟล์ถูกอ่านโดย Google Document AI และข้อความหลังปิดบังข้อมูลติดต่อถูกส่งให้โมเดลของ OpenAI, Anthropic และ Google เข้าถึงได้เฉพาะผู้วิจัย เก็บ 90 วันแล้วลบ ถอนตัวหรือขอลบข้อมูลได้ทุกเมื่อ อ่านเอกสารชี้แจงฉบับเต็มที่ [กรอก: ลิงก์]
