# เส้นทางข้อมูลไปยังผู้ให้บริการภายนอก

คอลัมน์นโยบายการใช้ข้อมูลต้องตรวจจากหน้านโยบายจริงของผู้ให้บริการในวันที่ทดสอบโมเดลจริง แล้วบันทึกลิงก์และวันที่ ห้ามกรอกจากความจำ

## 1. ผู้รับข้อมูล 4 บริการ (3 บริษัท) และที่เก็บของผู้วิจัย

| # | บริการ | บริษัท | ได้รับอะไร | ไม่ได้รับอะไร | ใช้ทำอะไร | ตำแหน่งประมวลผล | นโยบายการเก็บและใช้ข้อมูลผ่าน API | วันที่ตรวจ |
|---|---|---|---|---|---|---|---|---|

หมายเหตุ Google เป็นผู้รับข้อมูลสองทาง คือในฐานะผู้อ่านเอกสาร (Document AI) และในฐานะผู้ให้บริการโมเดล C (Gemini API) นอกเหนือจากบริการ Workspace ที่ใช้เป็นที่เก็บ จึงต้องระบุแยกในหนังสือยินยอมและตรวจนโยบายแต่ละบริการ

คำตัดสินที่ได้จากผู้ตรวจความหมาย (verifier) ถูกเก็บในเครื่องที่รัน n8n เป็นรหัสแฮชกับคำตัดสิน ไม่มีข้อความและไม่ส่งออกไปที่ใด

## 2. แผนภาพ

```
ผู้เข้าร่วม -- Google Forms (PDF, ตัวเลือก, ความยินยอม) --> Drive และ Sheets ของผู้วิจัย
                                                              |
                                      n8n บนเครื่องผู้วิจัย <--+ (บัญชีบริการ)
                                        |
        PDF ต้นฉบับ ---------------------+---------> [1] Google Document AI
                                        |                   | ข้อความ
                                        <-------------------+
                  normalize 5 กฎ และปิดบัง [EMAIL] [URL] [PHONE] [ID]
                                        | ข้อความหลังปิดบัง (sha256 เดียวกันทั้งสาม)
                    +-------------------+-------------------+
                    v                   v                   v
              [2] OpenAI          [3] Anthropic          [4] Google
                    +---------- JSON ผลประเมิน ----------------+
                                        | กฎ R0 ถึง R7 และจัดแผน (ในเครื่อง)
                                        v
                 รายงาน PDF บน Drive ผู้วิจัย -- Gmail OAuth2 ทีละฉบับ --> ผู้เข้าร่วม
```

## 3. คำตอบสำหรับคำถามที่คณะกรรมการน่าจะถาม

1. ส่งข้อมูลไปต่างประเทศหรือไม่ ส่ง (บริการ 1 ถึง 4) ฐานคือความยินยอมหลังแจ้งตามมาตรา 28 ดู `03_Data_Governance_PDPA`
2. ผู้ให้บริการนำไปฝึกโมเดลหรือไม่ ให้กรอกตามนโยบายจริงในตารางข้อ 1 พร้อมลิงก์และวันที่ตรวจ
3. ปิดบังอะไร อะไรยังหลุด ปิดบัง 4 รูปแบบ ชื่อบุคคล ที่อยู่ ชื่อบริษัท ชื่อสถาบันยังอาจอยู่ และ PDF ที่ส่งไปอ่านข้อความยังไม่ปิดบัง
4. ใครเข้าถึง เก็บที่ไหน นานเท่าไร ลบอย่างไร ผู้วิจัยคนเดียว ดู `03_Data_Governance_PDPA` หัวข้อ 4
5. ถ้าผลผิดแล้วผู้เข้าร่วมเสียประโยชน์ รายงานทุกฉบับระบุว่าเป็นผลวิจัยที่อ่านจากข้อความเท่านั้น ไม่ใช่การประเมินความสามารถหรือคำแนะนำอาชีพ ไม่ส่งให้บุคคลอื่น และไม่ใช้คัดเลือก
6. ถอนตัวหลังส่งผลได้หรือไม่ ได้ ข้อมูลถูกลบและตัดออกจากการวิเคราะห์ ดูเอกสารชี้แจง ข้อ 9
