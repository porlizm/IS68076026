```

                                                                 │

                                           ◄──────────────────────┘

                                           │ ข้อความหลังปิดบัง (sha256 เดียวกันทั้งสาม)
                       ┌───────────────────┼───────────────────┐

                 [2] OpenAI          [3] Anthropic          [4] Google
```

## 3. คำตอบสำหรับคำถามที่คณะกรรมการน่าจะถาม
1. **ส่งข้อมูลไปต่างประเทศไหม** ส่ง (บริการ 1–4) ฐานคือความยินยอมหลังแจ้งตาม ม.28 (ดู 03_Data_Governance)
2. **ผู้ให้บริการนำไปฝึกโมเดลไหม** ⚠ กรอกตามนโยบายจริงในตารางข้อ 1 พร้อม URL และวันที่ตรวจ
3. **ปิดบังอะไร อะไรยังหลุด** ปิดบัง 4 รูปแบบ · ชื่อบุคคล ที่อยู่ ชื่อบริษัท ชื่อสถาบันยังอาจอยู่ · PDF ที่ส่ง OCR ยังไม่ปิดบัง
4. **ใครเข้าถึง เก็บที่ไหน นานเท่าไร ลบอย่างไร** ดู 03_Data_Governance หัวข้อ 4
5. **ถ้าผลผิดแล้วผู้เข้าร่วมเสียประโยชน์** รายงานทุกฉบับระบุว่าเป็นผลวิจัยที่อ่านจากข้อความเท่านั้น ไม่ใช่การประเมินความสามารถหรือคำแนะนำอาชีพ ไม่ถูกส่งให้บุคคลอื่น และไม่ใช้คัดเลือก
6. **ถอนตัวหลังส่งผลได้ไหม** ได้ ข้อมูลถูกลบและตัดออกจากการวิเคราะห์ (ดู PIS ข้อ 9)
