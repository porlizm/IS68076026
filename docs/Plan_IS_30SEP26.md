## 5. การสร้างเล่มที่แก้ไขได้ (docx) จาก PDF

การเปิด PDF ใน Word ตรง ๆ ทำให้ภาษาไทย ตาราง และสมการเสียรูป จึงไม่แนะนำ

**วิธีที่เสนอ: ให้ Markdown เป็นต้นฉบับ แล้วใช้สคริปต์สร้าง docx**

1. **ดึงเนื้อหา**: แยก PDF → Markdown รายบท (`book/ch1.md` … `book/appendix_*.md`)
