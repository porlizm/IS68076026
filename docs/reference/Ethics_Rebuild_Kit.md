## สิ่งที่ผู้วิจัยต้องเตรียมเอง
- [ ] ใบรับรองการอบรมจริยธรรมการวิจัยในมนุษย์
- [ ] แบบฟอร์มยื่นของคณะกรรมการจริยธรรม KMITL (ไฟล์ Word จากเว็บสถาบัน)
- [ ] ชื่อ อีเมล และเบอร์ติดต่อของผู้วิจัย อาจารย์ที่ปรึกษา และสำนักงานจริยธรรม
- [ ] ข้อความประกาศรับสมัคร และช่องทางที่จะใช้ประกาศ

## ประเด็นที่คณะกรรมการน่าจะถาม (ต้องตอบได้ในเอกสาร)
1. ส่งข้อมูลส่วนบุคคลไปต่างประเทศหรือไม่ ใช้ฐานกฎหมายอะไร (ม.28–29)
2. ผู้ให้บริการโมเดลนำข้อมูลไปฝึกโมเดลหรือไม่ (ระบุนโยบาย API ของแต่ละรายและวันที่ตรวจ)
3. ปิดบังอะไรบ้างก่อนส่ง และอะไรที่ยังหลุดได้ (ชื่อบริษัท/สถานศึกษายังอยู่)
4. ใครเข้าถึงข้อมูลได้ เก็บที่ไหน นานเท่าไร ลบอย่างไร และมีหลักฐานการลบหรือไม่
5. ถ้าผลวิเคราะห์ผิดแล้วผู้เข้าร่วมเสียประโยชน์จะทำอย่างไร (ระบุชัดว่ารายงานเป็นงานวิจัย ไม่ใช่คำแนะนำอาชีพ)
6. ถอนตัวหลังส่งผลแล้วได้หรือไม่ และข้อมูลที่ให้รหัสไปแล้วจะจัดการอย่างไร
