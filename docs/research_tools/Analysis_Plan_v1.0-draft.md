## 1. หลักการ

1. นิยาม ตัวหาร และเกณฑ์อ่านผลทุกข้อ **กำหนดก่อนเห็นข้อมูลกลุ่มหลัก** และไม่เปลี่ยนหลังเห็นผล
2. ประเมินต้นแบบ **ไม่ทดสอบสมมติฐานทางสถิติ** รายงานค่าประมาณพร้อมช่วงความไม่แน่นอน 95%
3. ระบบ 3 โมเดล + กฎ = เงื่อนไขเดียว ไม่เปรียบเทียบโมเดล ไม่ทำ ablation ไม่ทดสอบความต่างรายอาชีพ (เล่ม 1.7, 3.9.4)
4. ถ้าไม่ถึงเกณฑ์ รายงานค่าจริงพร้อมวิเคราะห์สาเหตุ ห้ามปรับกฎ θ prompt หรือคลังเพื่อให้ผ่าน
5. ทุกสัดส่วนรายงานพร้อม **ตัวเศษและตัวหารดิบ**

## 2. ชุดข้อมูลที่วิเคราะห์

| กลุ่ม | นิยาม | ใช้ใน |
|---|---|---|
| main | ผู้เข้าร่วมกลุ่มหลักที่ผ่านเกณฑ์ หนึ่งงานต่อคน (`stage = delivered`) | RQ1, RQ2, κ |
| pilot | ผู้เข้าร่วมนำร่อง 5 คน | ปรับเครื่องมือเท่านั้น ไม่รวมผล |
| excluded | ถอนตัว ส่งซ้ำ หรือไม่ผ่านเกณฑ์ (ระบุเหตุผล) | รายงานจำนวน |

- บันทึกใน `cohort.csv` (run_id, cohort, reason) ก่อนวิเคราะห์ · หลายงานต่อคน → ใช้งานล่าสุดที่ delivered
- ผู้ที่ถอนตัวและขอลบข้อมูล → ตัดออกทั้งหมด รายงานจำนวน · ชุดทดสอบสังเคราะห์ไม่นับเป็นผู้เข้าร่วม

## 3. RQ1 ความถูกต้องของสถานะผลการตรวจหลักฐาน

หน่วยข้อมูล 1 ข้อกำหนด × 1 ผู้เข้าร่วม (สูงสุด 900) · **หน่วยสรุปผลหลักคือผู้เข้าร่วม** (เล่ม 3.2.2)

| ตัวชี้วัด | นิยาม | บทบาท |
|---|---|---|
| **Macro-F1 เฉลี่ยรายผู้เข้าร่วม** | ต่อคน: F1 ของ evidenced/partially/missing บนข้อที่สรุปได้ แล้วเฉลี่ยเท่ากัน → เฉลี่ยข้ามผู้เข้าร่วม | **ค่าหลัก** |
| Macro-F1 จากข้อมูลรวม | จากตาราง 3×4 รวมทุกคน | ประกอบ |
| Macro-F1 ประกอบ | precision เดิม · recall หารด้วยจำนวนในชุดคำตอบอ้างอิงทั้งแถว (abstained = ระบุผิด) | ประกอบ (เล่ม 3.9.3) |
| อัตราการไม่สรุป | abstained ÷ ข้อทั้งหมดที่ส่งวิเคราะห์ | รายงานคู่ Macro-F1 เสมอ |
| ตาราง 3×4 | สถานะอ้างอิง 3 แถว × ผลระบบ 4 คอลัมน์ จำนวนดิบ | อธิบายรูปแบบข้อผิดพลาด |
| U (สมการ 3.6) | รวมและรายโมเดล | ควบคุมคุณภาพ ไม่ใช้เปรียบเทียบโมเดล |

**ตัวหารเป็นศูนย์** (เล่ม 3.9.3): สถานะไม่มีในชุดคำตอบอ้างอิง → N/A ไม่นำเข้าเฉลี่ย · ระบบไม่เคยให้สถานะที่ชุดคำตอบอ้างอิงมี → F1 = 0 · รายงานจำนวนสถานะที่เฉลี่ยทุกครั้ง · ผู้เข้าร่วมที่ทุกข้อ abstained → ไม่นำเข้าค่าเฉลี่ย Macro-F1 แต่นับในอัตราการไม่สรุป

**ช่วงความไม่แน่นอน** bootstrap เปอร์เซ็นไทล์ที่ระดับผู้เข้าร่วม 2,000 รอบ seed 68076026 · ช่วง 2.5–97.5 (เล่ม 3.9.4)

**การวิเคราะห์ข้อผิดพลาด** (อธิบาย ไม่มีเกณฑ์): (1) อ้างอิง evidenced/partially แต่ระบบ missing แยก ก) กฎ R2/R3 ปรับเสียง ข) โมเดลตอบ missing เอง (2) อ้างอิง missing แต่ระบบให้ evidenced/partially (3) สับสน evidenced กับ partially (4) รายการที่ผู้ให้รหัสติ๊ก ocr_issue (5) สัดส่วนที่ผ่าน R3 ด้วยคำพ้อง (`R3_alias_hit`) (6) การกระจายความยาวข้อความอ้างอิงและสัดส่วนนอก 20–300 ตัวอักษร (7) รหัสรุ่นโมเดลที่ตอบกลับจริง ถ้าเปลี่ยนระหว่างเก็บรายงานแยก

## 4. ความน่าเชื่อถือของชุดคำตอบอ้างอิง

- ผู้ตรวจคนที่ 2 ให้รหัสอิสระ ≥ 20% ของผู้เข้าร่วม (6 คน = 180 รายการ) สุ่มแบบเป็นระบบจากลำดับการส่งแบบฟอร์ม + ทุกคนที่แจ้งไม่เห็นด้วย (รายงานแยก)
- Cohen's κ จาก **รหัสก่อนหาข้อยุติ** (`coder_1_status`, `coder_2_status`) · เกณฑ์ **κ ≥ 0.61**
- สัญญาณอคติ: Macro-F1 ของระบบบน 180 รายการเทียบรหัสของคนที่ 1 และคนที่ 2 ถ้าต่าง ≥ 0.05 อภิปรายในบทที่ 4

## 5. RQ2 ความเหมาะสมของเส้นทางการเรียนรู้

หน่วยวิเคราะห์ 1 แผนต่อผู้เข้าร่วม · นับรายการ **ไม่ซ้ำ** ภายในแผน · แผนสร้างจากผลระบบจริง ไม่แทนด้วยชุดคำตอบอ้างอิง

| ตัวชี้วัด | นิยาม (ตารางที่ 3.27) | เกณฑ์ |
|---|---|---|
| ความตรงประเด็น | รายการไม่ซ้ำที่ผู้ประเมินตัดสินว่าครอบคลุมช่องว่างอ้างอิง ≥ 1 ข้อ ÷ รายการไม่ซ้ำที่ตรวจ | ≥ 0.80 |
| ความครอบคลุมช่องว่าง | ช่องว่างอ้างอิงที่มีรายการในแผนรองรับ (ตาม covers_requirements และผู้ประเมินไม่ปฏิเสธคู่นั้น) ÷ ช่องว่างอ้างอิงทั้งหมดของผู้เรียน · ไม่มีช่องว่าง → N/A | ไม่มีเกณฑ์ ต้องอ่านคู่กับข้อจำกัดของคลังและเวลา (เล่ม 3.11) |
| ความถูกต้องของข้อมูลรายการ | รายการไม่ซ้ำที่รหัส ชื่อ ผู้ให้บริการ ลิงก์ และสถานะตรงคลัง ÷ รายการไม่ซ้ำ | = 1.00 |
| ความเป็นไปได้ด้านเวลา | แผนที่ชั่วโมงรวม ≤ Hmax ÷ แผนที่ไม่ว่าง (หนึ่งแผนต่อคน) | = 1.00 |
| ประโยชน์ที่รับรู้ 3 ข้อ | ค่าเฉลี่ย SD n การกระจาย 1–5 **รายข้อ** · "ประเมินไม่ได้" นับแยก · ไม่รวมเป็นคะแนนเดียว · ไม่เติมค่า | ค่าเฉลี่ยรายข้อ ≥ 3.5 |

กรณีพิเศษรายงานแยก 5 กรณี (เล่ม 3.9.2): แผนว่างเพราะไม่มีช่องว่าง · แผนว่างเพราะไม่มีรายการในคลัง · ไม่ทราบชั่วโมง · ส่งรายงานไม่สำเร็จ · ไม่ตอบแบบประเมิน · สาเหตุคำแนะนำไม่เหมาะสม 4 ประเภทรายงานจำนวน · คำตอบปลายเปิดจัดกลุ่มประเด็นและรายงานจำนวนผู้กล่าวถึง

ค่าเกณฑ์เดียวกันเขียนไว้ใน `analysis/run_analysis.py` (CRITERIA) และต้องตรงกันทุกค่า

## 7. ขั้นตอนปฏิบัติ

1. Export ทุกแท็บเป็น CSV ลง `private/exports/<YYYY-MM-DD>/` + เขียน `cohort.csv`
2. `python -m unittest discover -s analysis/tests -t .` ต้องผ่านทั้งหมด
3. `python analysis/run_analysis.py --exports private/exports/<วันที่> --out analysis/output/main --label MAIN`
4. ตรวจ `criteria.json` และ `report.md` → นำตารางไปใช้ในบทที่ 4
5. เก็บผลทั้งโฟลเดอร์ + sha256 ของไฟล์ export เป็นหลักฐาน (ผลต้องสร้างซ้ำได้เหมือนเดิม)
6. ซ้อมขั้นตอนทั้งหมดได้ด้วย `python analysis/run_analysis.py --synthetic --out analysis/output/rehearsal_synthetic` (ข้อมูลสังเคราะห์ 30+5 · ไม่ใช่ผลวิจัย)

## ภาคผนวก ก ตัวอย่างคำนวณ (เป้าของ unit test)

**ก.1 Macro-F1 และอัตราการไม่สรุป** ผู้เข้าร่วมสมมติ 20 รายการ

| อ้างอิง \ ระบบ | evidenced | partially | missing | abstained |
|---|---|---|---|---|
| evidenced | 6 | 1 | 0 | 1 |
| partially | 1 | 3 | 2 | 0 |
| missing | 0 | 0 | 5 | 1 |

- evidenced: P = 6/7 · R = 6/7 · F1 = 0.8571
- partially: P = 3/4 · R = 3/6 · F1 = 0.6000
- missing: P = 5/7 · R = 5/5 · F1 = 0.8333
- **Macro-F1 หลัก = 0.7635** · อัตราการไม่สรุป = 2/20 = 0.10
- ค่าประกอบ: recall ของ evidenced = 6/8 = 0.75 · missing = 5/6

**ก.2 Cohen's κ** 10 คู่ ตรงกัน 8 คู่ → po = 0.80 · สัดส่วนขอบของผู้ให้รหัส A = (0.4, 0.3, 0.3) B = (0.3, 0.3, 0.4) → pe = 0.33 → **κ = (0.80 − 0.33) / (1 − 0.33) = 0.7015**

**ก.3 RQ2** แผนหนึ่งมีรายการ I1 (ซ้ำสองแถว) และ I2 · ผู้ประเมินรับ I1→g1 ปฏิเสธ I1→g2 และ I2→g3 · ชื่อของ I2 ไม่ตรงคลัง · ช่องว่างอ้างอิง g1–g4 · ชั่วโมง 140 ≤ Hmax 150 → ตรงประเด็น 1/2 · ครอบคลุม 1/4 · ถูกต้องข้อมูล 1/2 · เวลา 1/1 · อีกแผนว่างเพราะไม่มีช่องว่าง → นับเป็นกรณีพิเศษ
