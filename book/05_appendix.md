# ภาคผนวก

ภาคผนวกเก็บรายละเอียดที่ใช้ตรวจย้อนหรือทำซ้ำงาน ตารางที่สร้างจากไฟล์ข้อมูลและ workflow จริงมาจากสคริปต์ของโครงการ ตัวเลขจึงตรงกับเนื้อหาในบทที่ 3

## ภาคผนวก ก คำอธิบายกรณีใช้งานรายกรณี

ภาคผนวกนี้ขยายตารางที่ 3.7 ตารางของแต่ละกรณีมีห้าแถว ได้แก่ ผู้กระทำ เงื่อนไขก่อน ลำดับหลัก ข้อยกเว้น และเงื่อนไขหลัง ชื่อโหนดในวงเล็บตรงกับ workflow {{wf_name}}

**ตารางที่ ก.1** UC-01 ส่งเรซูเมและเงื่อนไขการเรียน

| หัวข้อ | รายละเอียด |
|---|---|
| ผู้กระทำ | ผู้เข้าร่วม |

## ภาคผนวก ง ผลทดสอบด้วยข้อมูลสังเคราะห์

ภาคผนวกนี้ขยายตารางที่ 3.17 เรซูเมสังเคราะห์ทั้งสามกรณีเป็นข้อมูลที่ผู้วิจัยแต่งขึ้น ผลตอบกลับของโมเดลก็เป็นผลจำลองที่ผู้วิจัยเขียน โดยใส่ความผิดพลาดที่รู้ล่วงหน้า เพื่อดูว่ากฎตรวจจับได้หรือไม่

ผลตอบกลับจำลองของกรณี A มีข้อผิดพลาดสองแบบ แบบแรกคือการสรุปความแทนการคัดลอก ซึ่งกฎ R2 ต้องปฏิเสธ แบบที่สองคือการยกบรรทัดชื่อตำแหน่งงานมาเป็นหลักฐาน ซึ่งกฎ R3 ต้องปฏิเสธ กรณี B เพิ่มการพลิกสถานะของโมเดลหนึ่งตัวในบางข้อ ใช้ทดสอบว่าการรวมเสียงแก้ความเห็นที่ผิดของโมเดลเดียวได้ กรณี C ให้โมเดล C ตอบรหัส 429 ทุกครั้ง ระบบจึงเรียกซ้ำจนครบแล้วทำงานต่อด้วยสองโมเดล

**ตารางที่ ง.1** ผลการรันระบบกับเรซูเมสังเคราะห์

{{synthetic_table}}

ที่มา ผลการรันระบบด้วยผลตอบกลับจำลอง

กรณี C มีข้อที่ยังสรุปไม่ได้ {{cC_abstained}} ข้อ เพราะเมื่อเหลือสองโมเดลและสองโมเดลเห็นต่างกัน ไม่มีสถานะใดได้ถึงสองเสียง ข้อที่ระบบสรุปไม่ตรงเฉลยในกรณี A และ C เกิดจากความผิดพลาดที่ใส่ไว้โดยตั้งใจและผ่านกฎได้ เพราะข้อความมีอยู่จริงและมีคำที่เกี่ยวข้อง ตัวอย่างนี้แสดงข้อจำกัดของการตรวจระดับข้อความตามหัวข้อ 3.9
